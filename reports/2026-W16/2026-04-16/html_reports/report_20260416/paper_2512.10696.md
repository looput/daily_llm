# Remember Me, Refine Me: A Dynamic Procedural Memory Framework for Experience-Driven Agent Evolution

## 摘要

> 本文提出了一种名为ReMe的动态程序记忆框架，用于经验驱动的智能体进化。该框架通过多层面提炼、上下文自适应重用和基于效用的精炼三个机制，解决了现有记忆系统被动积累的问题。在BFCL-V3和AppWorld数据集上的实验表明，ReMe在智能体记忆系统中达到了新的最先进水平，并观察到显著的内存缩放效应。作者团队中包含Qwen（阿里千问）的研究人员，表明该研究具有工业界背景支持。

## 详细分析

> **社区热度**: ⭐ 44 (来自 papers.cool)

## 问题定义

论文旨在解决现有 LLM 代理“被动累积”式程序记忆系统的三大缺陷：

1. 粗粒度经验混杂噪声  
   传统方法以整条轨迹或整体工作流为存储单元，无关步骤与关键决策被同等保留，导致检索到的经验包含冗余甚至误导信息。

2. 经验复用缺乏情境适配  
   检索出的历史经验通常被直接拼接到提示中，不做语义层面的二次加工；当任务约束发生微小变化时，固定表述的经验反而降低代理性能。

3. 记忆池静态退化  
   缺少主动增删机制，随着任务分布漂移或模型能力提升，旧经验逐渐失效，记忆池演变为“有效洞察+有毒噪声”的混合体，持续拉低后续决策质量。

为此，作者提出动态程序记忆框架 ReMe，通过“细粒度蒸馏 → 情境自适应复用 → 基于效用的精炼”闭环，使代理能够自主提炼、改写并维护高质量经验，实现经验驱动的持续进化，而非简单累积。

## 相关工作

论文第 3 页“Related Works”将相关研究归为两条主线，并指出它们与 ReMe 的差异。可梳理如下：

- **Memory-enhanced LLM Agents**  
  - 参数记忆：WKM (Qiao et al., 2024) 把世界知识编码进模型权重，侧重规划而非经验复用。  
  - 非参数记忆：  
    – AWM (Wang et al., 2025) 自动归纳“工作流”并用于网页导航，但存储的是整条轨迹级摘要，无情境改写与淘汰机制。  
    – MARK (Ganguli et al., 2025) 构建用户偏好记忆，用于对话个性化，属于声明式记忆，与程序性经验蒸馏目标不同。  

- **Experience Learning Strategies**  
  - 轨迹即经验：Synapse (Zheng et al., 2024)、HiAgent (Hu et al., 2024) 直接缓存完整交互历史，缺乏抽象，难以泛化。  
  - 结构化技能蒸馏：  
    – Agent KB (Tang et al., 2025) 提取“经验单元”并做师生双阶段检索，但未考虑经验时效性与动态删减。  
    – CER (Liu et al., 2025)  distill 细粒度技能与环境动态，同样没有效用驱动的淘汰策略。  

综上，现有工作普遍停留在“静态累积”或“仅增不删”阶段，缺少  
1. 关键步骤级细粒度蒸馏  
2. 上下文感知的检索-重排-改写链路  
3. 基于重用效用的在线增删机制  

ReMe 在这三点上形成互补，构成首个贯穿“获取-复用-精炼”全生命周期的动态程序记忆框架。

## 解决方案

ReMe 用“三段式”闭环替代被动累积，把记忆从静态仓库升级为自进化认知基底：

1. 多面蒸馏（Experience Acquisition）  
   - 对每条轨迹做**成功模式识别**、**失败触发点定位**与**高低分对照分析**，提取关键步骤级洞察，而非整段流水账。  
   - 用 LLM-as-a-Judge 验证可行动性，再按语义嵌入去重，得到结构化经验  
     $E = \langle \omega, e, \kappa, c, \tau \rangle$。  

2. 情境自适应复用（Experience Reuse）  
   - 以**使用场景**$\omega$ 的向量做索引，检索 top-K 候选。  
   - 重排器按当前任务目标、约束再打分；重写器将多条经验融合为**任务专属**提示，实现“经验即演示”的即时适配。  

3. 效用驱动的精炼（Experience Refinement）  
   - **选择性新增**：仅把**成功轨迹**蒸馏入库；若遭遇失败，触发**失败感知反思**（≤3 次），成功后才能把教训写入，防止单点误判。  
   - **基于效用的删除**：对每条经验记录检索次数 $f$ 与成功贡献次数 $u$；当  
     $$f \ge \alpha \land \frac{u}{f} \le \beta$$  
     时自动剪枝，保证记忆池始终高信噪比。  

通过“细粒度萃取 → 情境化改写 → 在线增删”，ReMe 让代理在无需重训参数的情况下，持续沉淀高质量程序知识，实现经验驱动的终身进化。

## 实验验证

实验在 BFCL-V3 与 AppWorld 两个工具调用基准上完成，覆盖 2 类指标、3 组模型、4 类消融与 1 份错误分析，系统验证 ReMe 的有效性与可扩展性。

1. 主实验  
   - 模型：Qwen3-8B / 14B / 32B  
   - 指标：Avg@4（4 次平均成功率）与 Pass@4（4 次至少 1 次成功）  
   - 结果：  
     – ReMe(dynamic) 在三组模型上均取得 SOTA，Qwen3-8B+ReMe 平均 Pass@4 55.03%，**反超无记忆 Qwen3-14B 的 54.65%**，首次展示“记忆换规模”的 scaling 效应。  
     – 动态版本比固定版本平均再提升 2–4 个百分点，证明在线精炼必要。

2. 消融实验  
   - **粒度**：keypoint-level vs trajectory-level，前者 Avg@4 提升 1.5–2.2 倍。  
   - **组件**：  
     – 选择性新增 vs 全量新增：+3.50 % Avg@4；  
     – 加入失败反思：再 +0.67 %；  
     – 启用效用删除：最终 +3.83 % Pass@4。  
   - **检索键**：usage scenario 索引显著优于原始 query/关键词，平均领先 1–2 个百分点。  

3. 超参与扩展分析  
   - **K 值**：检索条数 5 时饱和，>5 因噪声反降。  
   - **LLMsumm 强度**：固定 LLMexecute=8B，把 summarizer 从 8B 换到 32B，Avg@4 再增 3.33 %，验证“更强蒸馏→更强代理”。  

4. 错误分析（Qwen3-8B on BFCL-V3）  
   - 总失败数由 62 → 47，其中 17 个基线独有错误被修复，仅引入 2 个新错误。  
   - 按错误类型：Reasoning Error 22→14，Action Omission 同步下降，表明经验复用显著削弱多步推理与工具链遗漏问题。

## 未来工作

- **动态检索时机**  
  目前只在任务开始时检索一次，可探索“每轮重检索”或“基于不确定性触发”的在线检索，以应对长程多轮任务中目标漂移的问题。

- **多层次记忆组织**  
  将程序记忆进一步细分为“技能级-子任务级-步骤级”三级索引，实现由粗到细的层次化复用，减少高阶技能被低阶细节淹没的风险。

- **经验质量的多维评估**  
  除 LLM-as-Judge 外，引入可学习的价值函数或规则验证器，对经验的一致性、可执行性与安全性做细粒度打分，降低误判入库概率。

- **小模型强蒸馏策略**  
  主实验显示更强的 LLMsumm 带来显著增益；未来可研究“大模型蒸馏→小模型摘要器”或“多智能体互评”方案，让 8B 模型也能生成接近 32B 质量的摘要，实现资源受限环境下的自我进化。

- **跨域迁移与防遗忘**  
  当前实验在同域任务内进行，可考察当任务分布发生领域漂移（如从股票交易到旅游规划）时，如何快速迁移旧经验并抑制与新环境冲突的条目，实现持续学习中的遗忘-迁移平衡。

- **经验可解释性与可视化**  
  为每条经验生成自然语言解释或因果图，使用户或开发者能直观理解“为何推荐此经验”，提升系统在真实业务中的可审计性与信任度。

- **与参数高效微调协同**  
  探索“经验即数据”——将高效用经验转化为指令-回答对，通过 LoRA/AdaLoRA 等 PEFT 方法做轻量级微调，实现外部记忆与内部参数的双通道协同进化。

## 总结

**ReMe：动态程序记忆框架驱动代理自我进化**

1. 问题  
   现有 LLM 代理把“怎么做”知识当成静态、只增不减的轨迹仓库，导致噪声累积、复用失效、性能退化。

2. 方案  
   提出 ReMe，用三段闭环替代被动累积：  
   - **多面蒸馏**——从成功/失败/对照中抽取关键步骤级经验，LLM-as-Judge 过滤并去重。  
   - **情境自适应复用**——以“使用场景”向量检索 + 重排 + 改写，把历史经验转化为当前任务专属提示。  
   - **效用驱动精炼**——只把成功轨迹入库；失败触发≤3 次反思，成功后提炼教训；同时按 $u/f≤β$ 剪枝低效用条目，实现记忆池自净化。

3. 结果  
   在 BFCL-V3 与 AppWorld 上，Qwen3-8B+ReMe 平均 Pass@4 达 55.03%，**反超无记忆 Qwen3-14B**，首次验证“记忆换规模”的 scaling 效应；动态版本一致优于固定版本，消融实验显示细粒度、选择性新增、效用删除各自带来显著增益。

4. 贡献  
   - 给出首个贯穿“获取-复用-精炼”全生命周期的动态程序记忆框架。  
   - 发布 reme.library 细粒度经验数据集。  
   - 证明高质量自进化记忆可作为参数扩张的替代路径，为资源受限场景提供终身学习新范式。
