## 摘要

> 本文提出了一种名为Tru-POMDP的新型任务规划方法，用于解决家庭服务机器人在真实世界中面临的不确定性规划问题。该方法创新性地结合了大型语言模型（LLM）的结构化信念生成与原则性的部分可观测马尔可夫决策过程（POMDP）规划，通过构建假设树（TOH）来系统性地生成高质量粒子信念，并设计了开放式的POMDP模型进行严格的贝叶斯信念跟踪和高效规划。在多样化的厨房环境复杂物体重排任务实验中，该方法显著优于当前最先进的基于LLM和LLM树搜索的混合规划器，在成功率、规划质量、鲁棒性和效率方面均表现出色。

## 详细分析

> **社区热度**: ⭐ 3 (来自 papers.cool)

## 问题定义

这篇论文试图解决家庭服务机器人在真实世界中执行任务时面临的不确定性问题。具体来说，机器人需要在部分可观测的环境中，根据模糊的人类指令、处理隐藏或未知位置的物体以及开放词汇表中的物体类型，来规划任务。这些因素导致了显著的开放性不确定性（open-ended uncertainty）和巨大的规划空间，使得任务规划变得极具挑战性。论文提出了一种名为 Tru-POMDP 的规划器，旨在通过结合结构化的信念生成（使用大型语言模型 LLMs）和基于部分可观测马尔可夫决策过程（POMDP）的规划，来有效应对这些挑战。

## 相关工作

论文中提到了以下相关研究：

### Online POMDP Planning
- **DESPOT [14]**: 提供了一种在线 POMDP 规划算法，通过信念树搜索来计算最优策略，并在每次决策时仅执行即时动作，然后根据新观察结果重新规划，以适应在线规划场景。
- **POMDP 基础理论 [15]**: 提供了 POMDP 的基本理论框架，包括状态、动作、观测、转移模型、观测模型、奖励函数和初始信念等定义，为 POMDP 规划提供了数学基础。

### Robot Planning with Large Language Models
- **ReAct [1]**: 一种基于 LLM 的闭环规划器，根据当前观测和环境的即时反馈选择动作。
- **Reflexion [2]**: ReAct 的扩展版本，引入了反思模块，当遇到连续失败时，会分析执行历史并生成修订计划以指导后续决策。
- **其他基于 LLM 的规划方法 [3, 4, 5, 6]**: 这些方法利用 LLM 作为规划器，通过提示工程或微调生成开环动作序列，或通过迭代反馈和反思产生闭环动作。

### Planning under Uncertainty with Large Language Models
- **LLM-MCTS [7]**: 使用 LLM 生成任务目标和隐藏物体放置的单一最大似然假设，然后执行蒙特卡洛树搜索（MCTS），在模拟过程中重复调用 LLM 以指导动作选择。
- **其他结合 LLM 和 POMDP 的方法 [9, 10, 11, 12]**: 这些方法利用 LLM 生成 POMDP 模型的某些元素，如信念或观测似然，然后将这些元素反馈到 LLM 中以提高其在不确定性下的规划能力。然而，这些方法仍然依赖于 LLM 的隐式推理，缺乏明确的信念跟踪和树搜索规划所提供的正式保证。

这些相关研究为 Tru-POMDP 的提出提供了背景和基础，Tru-POMDP 通过结合 LLM 的常识推理能力和 POMDP 的明确信念跟踪和规划，克服了现有方法在处理开放性不确定性时的局限性。

## 解决方案

论文通过提出 Tru-POMDP（Task planning under Uncertainty via Tree of Hypotheses and Open-Ended POMDPs）来解决家庭服务机器人在不确定性环境下进行任务规划的问题。Tru-POMDP 结合了大型语言模型（LLM）的结构化信念生成和基于部分可观测马尔可夫决策过程（POMDP）的规划，具体方法如下：

### 1. Tree of Hypotheses (TOH)
- **目标**：构建一个关于可能世界状态和任务目标的树状假设结构，以形成常识信念。
- **过程**：
  - **Level 1**：生成目标对象的假设。LLM 根据任务指令和观测到的场景图，预测可能与任务相关的对象组合，并为每种组合分配置信度。
  - **Level 2**：生成放置目标的假设。对于每组目标对象，LLM 推断每个对象的目标区域，形成可能的目标放置。
  - **Level 3**：生成当前放置的假设。对于在初始观测中不可见的目标对象，LLM 预测其可能的初始位置。
- **结果**：通过从根到叶的路径定义采样粒子，每个粒子包含一个假设的完整场景图和对应的目标放置，形成 LLM 推理的粒子信念。

### 2. Hybrid Belief Update
- **目标**：通过贝叶斯滤波和 LLM 生成的信念相结合，维护一个一致且高效的粒子信念。
- **过程**：
  - **贝叶斯滤波**：使用粒子滤波进行信念更新，包括预测步骤（模拟上一动作对场景图的影响）和消除步骤（移除与新观测不一致的粒子）。
  - **LLM 粒子补充**：当信念的总权重低于阈值时，调用 TOH 模块生成新的粒子来补充信念，确保信念保持有效的概率分布。

### 3. Online POMDP Planning
- **目标**：在当前信念下计算最优策略。
- **过程**：
  - **动态动作空间**：根据当前信念动态构建动作空间，包括 OPEN、PICK 和 PLACE 动作，确保动作空间紧凑且具有足够的表达能力。
  - **信念树搜索**：基于 DESPOT 算法，递归探索从当前信念出发的未来动作-观测序列，使用 Bellman 原理迭代更新信念节点的价值估计，并利用价值估计作为树搜索的启发式函数。
  - **LLM 生成的 rollout 策略**：在信念树的叶节点处，使用 LLM 生成的 rollout 策略来提供启发式下界，通过模拟 rollout 策略来估计从叶节点开始的累积奖励。

### 4. 实验验证
- **实验设置**：在 RoboCasa 的五个厨房环境中进行实验，任务涉及模糊指令、大量隐藏空间和开放词汇表对象。
- **性能指标**：使用累积奖励、成功率、步数、规划时间和 LLM token 使用量等指标评估性能。
- **结果**：Tru-POMDP 在成功率、计划质量和对模糊性和遮挡的鲁棒性方面显著优于基于 LLM 的和基于 LLM 树搜索的混合规划器，同时具有更高的规划效率和更低的 LLM token 使用量。

通过上述方法，Tru-POMDP 有效地解决了家庭服务机器人在不确定性环境下的任务规划问题，通过结合 LLM 的常识推理能力和 POMDP 的明确信念跟踪和规划，实现了在复杂环境中的高效和鲁棒规划。

## 实验验证

论文通过一系列实验来验证 Tru-POMDP 在处理家庭服务机器人任务规划中的不确定性和模糊性方面的有效性。以下是实验的详细设置和结果：

### 实验设置
- **环境**：使用 RoboCasa [13] 的五个厨房环境，包括 One Wall、One Wall with Island、L-Shaped、L-Shaped with Island 和 Galley。每个环境中包含多个隐藏区域，如橱柜、抽屉等。
- **任务生成**：通过 LLM 辅助生成复杂的对象重排任务，任务包括模糊的自然语言指令、目标相关对象及其初始放置位置、干扰对象及其初始放置位置，以及满足指令要求的目标状态集合。
- **任务难度**：根据目标对象的数量将任务分为三个难度级别：简单（2 个目标对象）、中等（3 个目标对象）和困难（4-8 个目标对象）。每个难度级别生成 100 个任务，总共 300 个任务。
- **性能指标**：使用累积奖励、成功率、步数、规划时间和 LLM token 使用量等指标评估性能。
- **基线方法**：与以下基线方法进行比较：
  - ReAct [1]：基于 LLM 的闭环规划器。
  - Reflexion [2]：ReAct 的扩展版本，引入了反思模块。
  - ReAct* 和 Reflexion*：在 ReAct 和 Reflexion 的基础上，通过提供额外的结构化任务域描述来增强 LLM 的性能。
  - LLM-MCTS [7]：使用 LLM 生成单一最大似然假设，然后执行蒙特卡洛树搜索（MCTS）。

### 实验结果
- **累积奖励**：Tru-POMDP 在所有任务中均获得了最高的累积奖励，表明其能够更有效地完成任务。
- **成功率**：Tru-POMDP 在不同难度级别的任务中均表现出最高的成功率，尤其是在高难度任务中，其成功率显著高于其他基线方法。
- **步数**：Tru-POMDP 在完成任务时所需的步数较少，表明其规划效率更高。
- **规划时间**：Tru-POMDP 的规划时间较短，尤其是在高难度任务中，其规划时间显著低于其他基线方法。
- **LLM token 使用量**：Tru-POMDP 在完成任务时消耗的 LLM token 数量最少，表明其在利用 LLM 能力时更加高效。

### 消融研究
为了验证 Tru-POMDP 中各个模块的重要性，论文还进行了消融研究，结果表明：
- **去除信念空间规划（w/o Belief）**：仅依赖单一最可能假设的规划器性能大幅下降，表明信念空间规划对于处理不确定性至关重要。
- **去除混合信念更新（w/o HBU）**：不使用贝叶斯滤波更新信念的规划器在高难度任务中的性能显著下降，且规划时间大幅增加。
- **去除树状假设结构（w/o TOH）**：直接从 LLM 生成扁平粒子假设的规划器性能较差，表明树状假设结构对于生成高质量信念至关重要。
- **去除 LLM 生成的 rollout 策略（w/o LRP）**：使用简单随机策略替代 LLM 生成的 rollout 策略的规划器性能大幅下降，表明 LLM 生成的 rollout 策略对于树搜索的启发式引导至关重要。
- **去除信念树搜索（w/o BTS）**：直接将粒子信念输入 LLM 并让其输出下一个动作的规划器性能最差，表明信念树搜索对于高效规划至关重要。

### 结论
实验结果表明，Tru-POMDP 在处理家庭服务机器人任务规划中的不确定性和模糊性方面具有显著优势。通过结合 LLM 的常识推理能力和 POMDP 的明确信念跟踪和规划，Tru-POMDP 能够在复杂环境中实现高效、鲁棒的任务规划。

## 未来工作

尽管 Tru-POMDP 在处理家庭服务机器人任务规划中的不确定性和模糊性方面取得了显著成果，但仍有一些可以进一步探索的方向：

### 1. **优化 Tree of Hypotheses (TOH) 的效率**
- **问题**：TOH 模块需要多次调用 LLM，这可能会导致计算开销较大。
- **探索方向**：
  - **LLM 微调**：通过微调 LLM，使其能够更快地生成高质量的假设，从而减少调用次数。
  - **并行化处理**：利用多线程或分布式计算来并行处理 TOH 的各个层级，提高生成假设的效率。
  - **预训练和缓存**：对于常见的任务和场景，可以预先训练并缓存一些假设，以减少实时生成的开销。

### 2. **处理感知噪声和随机动作结果**
- **问题**：当前实验假设了无噪声的感知和确定性的动作结果，但在真实环境中，感知和动作往往是不确定的。
- **探索方向**：
  - **扩展 POMDP 模型**：在 POMDP 模型中加入感知噪声和动作随机性的概率模型，使规划器能够更好地处理这些不确定性。
  - **鲁棒性测试**：在包含感知噪声和随机动作结果的环境中进行实验，验证 Tru-POMDP 的鲁棒性，并根据需要调整算法。

### 3. **扩展到更广泛的任务和动作空间**
- **问题**：当前研究主要集中在对象重排任务上，动作空间相对有限。
- **探索方向**：
  - **多样化任务**：将 Tru-POMDP 应用于更广泛的家庭服务任务，如清洁、烹饪等，这些任务可能涉及更复杂的动作和对象属性。
  - **扩展动作空间**：增加动作空间的复杂性，例如引入多步动作、条件动作和复合动作，以处理更复杂的任务。

### 4. **改进 LLM 生成的 rollout 策略**
- **问题**：当前的 LLM 生成的 rollout 策略虽然有效，但可能仍有改进空间。
- **探索方向**：
  - **策略优化**：通过强化学习或其他优化方法，进一步提高 LLM 生成的 rollout 策略的质量。
  - **策略适应性**：使 rollout 策略能够根据不同的任务和环境动态调整，提高其适应性和泛化能力。

### 5. **结合多模态信息**
- **问题**：当前方法主要依赖于文本描述和 LLM 的推理能力，而忽略了视觉、听觉等多模态信息。
- **探索方向**：
  - **多模态输入**：将视觉、听觉等多模态信息整合到任务规划中，使机器人能够更全面地理解和感知环境。
  - **多模态 LLM**：探索使用多模态 LLM，这些模型能够处理和融合多种模态的信息，从而提高规划的准确性和效率。

### 6. **长期任务规划和学习**
- **问题**：当前的规划主要集中在短期任务上，对于长期任务和持续学习的需求尚未充分探索。
- **探索方向**：
  - **长期规划**：研究如何将 Tru-POMDP 扩展到长期任务规划，使机器人能够处理多阶段任务和长期目标。
  - **持续学习**：引入持续学习机制，使机器人能够在执行任务的过程中不断学习和优化其规划策略。

### 7. **实际部署和用户交互**
- **问题**：当前研究主要在模拟环境中进行，实际部署和用户交互方面的研究较少。
- **探索方向**：
  - **实际部署**：在真实环境中部署 Tru-POMDP，验证其在实际家庭服务任务中的性能和鲁棒性。
  - **用户交互**：研究如何使机器人能够更好地与用户交互，例如通过自然语言对话、手势等方式，提高任务规划的灵活性和用户体验。

通过这些方向的进一步探索，Tru-POMDP 可以在更复杂的实际场景中发挥更大的作用，为家庭服务机器人的发展提供更强大的技术支持。

## 总结

论文提出了一种名为 Tru-POMDP 的方法，用于解决家庭服务机器人在不确定性环境下的任务规划问题。Tru-POMDP 结合了大型语言模型（LLM）的结构化信念生成和基于部分可观测马尔可夫决策过程（POMDP）的规划，通过三个主要模块实现高效的任务规划：

1. **Tree of Hypotheses (TOH)**：
   - 构建一个关于可能世界状态和任务目标的树状假设结构，以形成常识信念。
   - 通过 LLM 生成目标对象、放置目标和当前放置的假设，形成高质量的粒子信念。

2. **Hybrid Belief Update**：
   - 通过贝叶斯滤波和 LLM 生成的信念相结合，维护一个一致且高效的粒子信念。
   - 在信念更新过程中，使用粒子滤波进行平滑和可靠的更新，并在必要时通过 LLM 补充新的粒子。

3. **Online POMDP Planning**：
   - 在当前信念下计算最优策略，通过信念树搜索和动态动作空间构建，实现高效的在线规划。
   - 使用 LLM 生成的 rollout 策略为树搜索提供启发式引导，确保规划的高效性和准确性。

### 实验验证

### 未来工作
论文提出了未来可以进一步探索的方向，包括优化 TOH 的效率、处理感知噪声和随机动作结果、扩展到更广泛的任务和动作空间、改进 LLM 生成的 rollout 策略、结合多模态信息、长期任务规划和学习，以及实际部署和用户交互。
