# ARISE: Agent Reasoning with Intrinsic Skill Evolution in Hierarchical Reinforcement Learning

**arXiv**: [2603.16060](https://arxiv.org/abs/2603.16060) · [PDF](https://arxiv.org/pdf/2603.16060)  
**领域**: Agent  
**作者**: Li, Miao, Qi, Lan  
**综合评分**: 8.36  （novelty: 9.0 · method: 8.5 · evidence: 9.0 · clarity: 7.5）

---

## 摘要

> 本文提出了一种名为ARISE（Agent Reasoning via Intrinsic Skill Evolution）的分层强化学习框架，旨在解决语言模型数学推理任务中策略复用性不足的问题。该框架通过高层技能管理和低层响应生成的双层策略，结合技能库的演化机制，显著提升了模型在数学推理任务上的性能，特别是在分布外任务上表现出色。论文实验设计严谨，在多个基准测试上验证了有效性，并开源了代码。

## 详细分析

## 问题定义
论文试图解决的核心问题是：在基于可验证奖励的强化学习（RLVR）范式下，如何让大型语言模型（LLM）在数学推理训练中，能够积累和重用跨问题实例的、可复用的推理策略（技能），而不是将每个问题视为孤立任务。现有方法在训练过程中生成的成功推理策略在每次尝试后即被丢弃，导致学习效率低下，且无法实现知识的跨任务迁移。具体而言，论文指出了现有技能增强方法的两个关键局限性：1) 技能管理（包括执行前的技能选择和执行后的技能总结）被委托给与策略梯度解耦的外部检索器，导致策略无法直接塑造技能选择偏好；2) 技能库的更新独立于强化学习目标，破坏了策略改进与技能库丰富化之间的反馈循环。

## 相关工作
相关工作主要分为两大类：
1.  **基于可验证奖励的强化学习（RLVR）方法**：以GRPO（Group Relative Policy Optimization）及其变体（如Dr.GRPO、DAPO、GSPO）为代表。这些方法通过组内归一化奖励来估计优势，避免了训练奖励模型的开销，专注于提升单次推理的性能，但未考虑跨问题的经验积累。
2.  **记忆与技能增强方法**：旨在为智能体提供可重用的知识结构。
    *   **推理时方法**：如Reflexion、ExpeL、SimpleMem，在推理时从外部记忆中检索相关轨迹或知识，但记忆库的构建独立于策略学习，且一旦构建即固定。
    *   **训练时集成方法**：如EvolveR、SkillRL和SAGE，将技能结构直接集成到训练循环中，通过轨迹蒸馏构建技能库。然而，这些方法通常仍依赖外部检索器进行技能选择，且技能库的更新与策略优化目标未完全统一。

**与现有工作的关系**：ARISE直接建立在SAGE等工作的基础上，但旨在克服其核心局限。它通过一个统一的、端到端的层次化策略，将技能选择、生成和策略优化紧密耦合，使技能库成为智能体状态的内在组成部分，并与策略共同进化。

## 解决方案
论文提出了ARISE（Agent Reasoning via Intrinsic Skill Evolution）框架，其核心是一个统一的、层次化的强化学习框架，由一个共享的策略参数化，同时扮演**技能管理器（Manager）**和**工作者（Worker）**的角色。

**核心方法包括：**
1.  **进化技能MDP（ES-MDP）**：将技能库建模为智能体内生状态的一部分，形式化定义了包含查询分布、库配置、动作空间、库转移函数和层次化奖励的MDP。这使得策略和库可以在统一的RL目标下联合优化。
2.  **策略驱动的技能选择**：管理器使用策略本身的条件对数概率（公式2）来评估当前查询与库中每个技能文档的相关性，并通过ε-greedy策略（公式3）选择技能。一个置信度门控机制过滤掉相关性低的技能。由于选择机制由策略参数直接控制，来自层次化奖励的优势信号可以端到端地传播，直接塑造技能选择偏好。
3.  **技能生成与两阶段训练**：
    *   **技能生成**：在标准的G个解决方案rollout之外，执行一个额外的技能生成rollout（O_{G+1}）。该rollout以原始查询和具有正优势的成功解决方案轨迹为条件，将它们总结为结构化的技能文档（包含技能名称、问题类型、关键洞察、步骤方法等）。
    *   **两阶段训练**：**阶段I（预热）**：禁用技能选择，使用标准GRPO和二元任务奖励训练基础策略，同时通过O_{G+1}静默地填充技能库。**阶段II（技能增强GRPO）**：激活完整的层次化流程，管理器开始选择技能，奖励切换为层次化奖励，策略优化、技能选择和库丰富化联合进行。
4.  **层次化奖励设计**：奖励R ∈ {r0, r1, r2}，其中r2 > r1 > r0。具体设置为：错误答案（r0=0），正确答案但未使用技能（r1=1），正确答案且使用了技能（r2=2）。这种设计在组内相对优势计算中，明确奖励了有效利用技能的行为，激励策略学习选择和使用有用的技能。
5.  **两层技能库架构**：包含一个容量较小的**缓存（Cache）**作为技能选择的活跃池，和一个容量较大的**储备库（Reservoir）**作为技能存档。通过五种管理操作（添加、更新、驱逐、加载、删除）动态维护库的质量，确保库与策略共同进化。

## 实验验证
**实验设计**：
*   **基础模型**：Qwen3-4B-Instruct-2507 和 Phi-4-mini-instruct。
*   **训练数据**：DeepScaleR数据集（约40K个数学问题）。
*   **基线方法**：GRPO家族方法（GRPO, Dr.GRPO, DAPO, GSPO）和记忆/技能增强方法（EvolveR, SimpleMem, SkillRL）。
*   **评估基准**：
    *   **分布内**：AMC 2023和AIME 2024&2025竞赛题。
    *   **分布外**：Omni-MATH基准（包含代数、数论、组合、几何四个领域的奥赛级问题）。
*   **评估指标**：Pass@1准确率（32次运行平均）。

**主要结果**：
1.  **整体性能**：在两个基础模型和所有基准上，ARISE均一致优于所有基线方法。在Qwen3-4B上，ARISE在分布内任务上比最强的GRPO家族方法高出超过1个百分点。在能力较弱的Phi-4-mini上，ARISE也取得了最高分，证明了其有效性。
2.  **分布外泛化**：ARISE的优势在Omni-MATH上更为明显。在Qwen3-4B和Phi-4-mini上，ARISE分别比GRPO平均高出2.9和1.9个百分点，且在四个子领域均有提升（代数领域提升最大）。这表明进化的技能库促进了向未见数学领域的知识迁移。
3.  **消融实验**：
    *   **层次化奖励**：使用二元奖励导致最大精度下降，技能利用率从73%降至31%，证明层次化信号是技能采用的主要驱动力。
    *   **随机技能注入**：虽然保持了高利用率，但精度下降，证实了相关技能选择的重要性。
    *   **移除技能生成rollout**：冻结技能库（仅24个种子技能）对Omni-MATH影响最大，表明静态启发式无法覆盖奥赛问题的多样性。
    *   **移除置信度门控**：影响最小，但将利用率推至91%，证实其作为噪声过滤器的作用。
4.  **协同进化分析**：训练动态显示，一旦进入阶段II，ARISE的性能与技能库增长同步提升。后期库大小趋于饱和，但准确率持续改善，表明后期增益更多来自策略更有效地选择现有技能，而非积累新技能。

## 未来工作
**局限性及未来探索方向**：
1.  **任务领域局限**：当前框架仅在数学推理任务上进行了评估。未来可扩展到多工具智能体任务和代码生成等领域，其中可重用技能可能表现为可执行程序而非推理启发式。
2.  **技能形式与泛化**：技能文档目前采用固定的文本模式。探索更灵活或结构化的技能表示（如代码片段、图结构）可能进一步提升泛化能力和跨领域迁移。
3.  **计算开销**：额外的技能生成rollout（O_{G+1}）和持续的库管理操作引入了额外的计算和内存开销。未来工作可以优化这些操作的效率。
4.  **长期技能演化**：论文观察到后期库大小饱和。更长时间尺度下的技能演化动态、技能淘汰与复兴机制，以及如何避免技能库“僵化”值得进一步研究。
5.  **理论基础**：对进化技能MDP（ES-MDP）的收敛性、最优性等理论性质的分析可以加深对该框架的理解。

## 总结
**主要贡献和价值**：
1.  **提出了统一的层次化RL框架（ARISE）**：创新地将技能管理器和工作者的角色集成到一个共享策略中，实现了技能选择、生成与策略优化的端到端联合优化。
2.  **形式化了进化技能MDP（ES-MDP）**：为将技能库作为内生状态进行联合优化提供了形式化基础。
3.  **设计了策略驱动的技能选择机制**：摒弃了外部检索器，使策略梯度能够直接塑造技能选择偏好，这是与现有技能增强方法的关键区别。
4.  **引入了协同进化的训练动态**：通过层次化奖励和两阶段训练，创造了策略改进与技能库丰富化相互促进的正反馈循环。
5.  **提供了有力的实证证据**：在多个模型和基准（尤其是分布外任务）上展示了显著且一致的性能提升，并通过详尽的消融实验验证了各核心组件的必要性。

**总体价值**：ARISE为如何使LLM智能体在强化学习训练中实现持续的知识积累和技能演化提供了一个有前景的范式。它超越了孤立问题求解，迈向了一个能够通过内部技能库自主学习和复用策略的、更具适应性和泛化能力的智能体架构。
