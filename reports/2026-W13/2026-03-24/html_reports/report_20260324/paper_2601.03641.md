# Agent-Dice: Disentangling Knowledge Updates via Geometric Consensus for Agent Continual Learning

## 摘要

> 本文提出了一种名为Agent-Dice的参数融合框架，旨在解决基于大语言模型（LLM）的智能体在持续学习（Continual Learning）中面临的稳定性-可塑性困境。该方法通过几何共识评估，将知识更新解耦为两个阶段：几何共识过滤以修剪冲突梯度，以及基于曲率的重要性加权以增强共享语义。论文提供了严格的理论分析，并在GUI智能体和工具使用智能体领域进行了广泛的实验验证，证明了其出色的持续学习性能，且计算开销和参数更新量最小。代码已开源。

## 问题定义

论文旨在解决**基于大语言模型（LLM）的智能体在持续学习（continual learning）过程中面临的稳定性–可塑性困境（stability–plasticity dilemma）**。具体而言：

- **稳定性**要求智能体保留旧任务的知识，避免灾难性遗忘（catastrophic forgetting）；
- **可塑性**要求智能体快速适应新任务，吸收新知识。

现有方法难以**显式区分“跨任务共享的通用知识”与“任务间冲突的特定知识”**，导致在融合多任务参数更新时，通用知识被干扰、冲突知识被保留，从而加剧遗忘或阻碍新学习。

为此，作者提出**Agent-Dice**，通过**几何共识过滤（geometric consensus filtering）**与**曲率加权（curvature-based importance weighting）**两阶段参数融合框架，在**无需额外内存模块或重训练**的前提下，实现：

1. **剔除冲突梯度**，保障稳定性；
2. **强化共享语义**，提升可塑性；
3. **理论保证**融合更新等价于对多任务联合目标的梯度下降；
4. **极低计算开销**（GPU≈1 分钟，CPU≈10 分钟）即可完成多任务持续学习。

### 3. 理论根基

- **Linear Mode Connectivity (LMC)**  
  Mirzadeh et al. 2021 指出大模型在多任务微调后仍保持线性连通性，为 Agent-Dice 的“线性组合即梯度下降”提供前提（Theorem 1）。

- **Maximum Entropy & Boltzmann Distribution**  
  借用统计力学思想，将参数重要性视为“能量”，推导出 Softmax 形式的最优权重（Theorem 3），与信息论中的最大熵原理一致。

---

### 小结

Agent-Dice 与现有研究的最大差异在于：

1. **零 replay、零额外参数、零任务标识**；  
2. **显式分离“冲突”与“共享”**：先投票过滤冲突方向，再用曲率加权强化共享方向；  
3. **提供三重理论保证**：线性近似、误差指数衰减、最大熵权重；  
4. **在 GUI & Tool-use 两大 agent 场景**上首次验证了**持续学习无需重训练**的可行性。

## 解决方案

论文提出 **Agent-Dice**，一套**“两阶段参数融合”**框架，在**不引入额外内存、不重训、不增参**的前提下，把多个任务微调后产生的任务向量 τk 合并成一次更新，从而一次性解决稳定性–可塑性困境。具体流程如下（对应原文 §3.2 与图 2）：

---

### 阶段一：几何共识过滤（Geometric Consensus Filtering）

1. 对**每个参数 i** 单独投票  
   记 sk,i=sgn(τk,i)∈{0,1}，统计 K 个任务中“正/负”票数  
   Vi=∑k sk,i

2. 按多数阈值 δ=K/2 构造活跃集 Si  
   Si=  
   ⎧  
   ⎨  
   ⎩  
   {k | sk,i=1},  Vi>δ  
   {k | sk,i=0},  Vi<K−δ  
   {1..K},      否则（平票时保留全部）

3. 把不在 Si 的任务权重强制置 0 → **剔除与主流方向冲突的梯度**  
   理论保证（Theorem 2）：错误概率随 |Si| 指数下降  
   $$  
   P(\text{error}) \le \exp\!\bigl(-2|S_i|(p-0.5)^2\bigr)
   $$

---

### 阶段二：曲率加权（Curvature-based Importance Weighting）

1. 用**更新幅值** |τk,i| 近似局部曲率（高曲率=高显著性）

2. 在活跃集 Si 内做**掩码 Softmax**  
   wk,i=  
   ⎧  
   ⎨  
   ⎩  
   \frac{\exp(β|τk,i|)}{\sum_{j∈Si}\exp(β|τj,i|)},  k∈Si  
   0,  k∉Si  
   其中 β 为逆温度，文中直接取 1。

3. 理论保证（Theorem 3）：该分布是**最大熵**意义下、满足期望显著性约束的唯一解，避免人为偏置。

---

### 最终融合（Final Fusion）

将两阶段得到的权重矩阵 Wk=(wk,i) 与任务向量做**逐元素乘积**并求和  
$$  
θ_{\text{fused}} = θ_{\text{pre}} + \sum_{k=1}^K W_k ⊙ τ_k  
$$

由 Theorem 1 可知，该更新等价于对** surrogate 多任务目标**  
$$  
\tilde{L}(θ)=\sum_{k=1}^K w_k^{\top} L_k(θ)  
$$  
执行一步梯度下降，从而**同时优化所有任务**。

---

### 算法伪代码（精简版）

```
输入：预训练参数 θpre，各任务向量 {τ1…τK}
输出：融合后参数 θfused

for 每个参数 i in 1…d:
    // 阶段 1：投票
    Vi = Σk 1[τk,i≥0]
    Si = 多数集( Vi, K/2 )
    // 阶段 2：曲率加权
    for k in Si:
        wk,i = exp(|τk,i|) / Σj∈Si exp(|τj,i|)
    for k not in Si:
        wk,i = 0
// 融合
θfused = θpre + Σk wk ⊙ τk
```

- **Tool-use 场景**：在 ToolACE 四任务序列上，Agent-Dice 取得 **0.79/0.51** 的平均 Z-score，显著优于直接连续微调（0.06/0.38）（表 3-4）。

### 一句话总结

Agent-Dice 通过“**先投票去冲突，再按曲率给信心**”的逐参数融合策略，在**理论保证**与**零额外成本**的前提下，一次性实现**不遗忘旧知识、快速吸收新知识**的持续学习目标。

## 总结

**Agent-Dice: Disentangling Knowledge Updates via Geometric Consensus for Agent Continual Learning**  
一句话总结：  
**首次用“几何共识+曲率加权”两阶段参数融合，让 LLM 智能体在**零 replay、零额外内存、1 分钟 GPU 开销**内完成持续学习，理论证明显式剔除冲突梯度即可同时获得稳定性与可塑性。**

---

### 1 问题
- LLM 智能体落地 GUI/工具场景需**持续学会新任务**  
- 稳定性–可塑性困境根因：**无法区分“共享知识”与“冲突知识”**  
- 现有 replay/正则/结构法都**未显式解耦**，导致遗忘或干扰

---

### 2 方法（Agent-Dice）
两阶段**元素级参数融合**：

| 阶段 | 目的 | 操作 | 理论保证 |
|---|---|---|---|
| ① 几何共识过滤 | 去冲突、保稳定 | 逐参数投票，少数派权重置 0 | 错误概率指数下降（Hoeffding） |
| ② 曲率加权 | 强化共享、增塑性 | 在幸存集内用 Softmax 按 |τk,i| 加权 | 最大熵分布（Boltzmann） |

最终更新：  
$$θ_{\text{fused}} = θ_{\text{pre}} + \sum_k W_k ⊙ τ_k$$  
等价于一步梯度下降 on  surrogate 多任务目标（Theorem 1）。
