# FACTUM: Mechanistic Detection of Citation Hallucination in Long-Form RAG

**arXiv**: [2601.05866](https://arxiv.org/abs/2601.05866) · [PDF](https://arxiv.org/pdf/2601.05866)  
**领域**: Hallucination  
**作者**: Dassen, Kotula, Murray, Yates, Lawrie, Kayi, Mayfield, Duh  
**综合评分**: 7.98  （novelty: 9.0 · method: 8.5 · evidence: 8.5 · clarity: 8.0）

## 摘要

> 本文提出了一种名为FACTUM的机制性框架，用于检测长文本检索增强生成（RAG）模型中的引用幻觉问题。论文创新性地将引用幻觉重新定义为注意力（阅读）和前馈网络（回忆）路径之间一种随模型规模演变的协调失败，并设计了四个机制性评分指标来捕捉这种复杂交互。实验表明，FACTUM在AUC指标上显著优于现有基线方法。作者团队来自约翰斯·霍普金斯大学（Dassen, Kotula, Murray, Yates, Lawrie, Kayi, Mayfield, Duh），在自然语言处理和信息检索领域具有深厚的研究背景。

## 详细分析

> **社区热度**: ⭐ 3 (来自 papers.cool)

## 问题定义

论文聚焦“引文幻觉”（citation hallucination）——即模型在生成内容时把事实正确但来源错误的引文归因到并不支持该说法的文献上。传统 RAG 幻觉研究多把失败简单归因于“过度依赖参数知识”，本文指出该解释对引文场景并不充分，提出需要刻画模型内部注意力与 FFN 两条通路在引文生成瞬间的协同状态。为此，作者设计 FACTUM 框架，用四项可解释机制指标（上下文对齐、句首注意力、参数强度、通路对齐）捕捉“读”与“忆”两条信息流的耦合特征，实现长文本多文档场景下引文幻觉的 token 级检测，并揭示该机制签名随模型规模演化的规律。

## 相关工作

- **RAG 幻觉检测**  
  - 黑盒方法：用外部 LLM 做裁判 [10,41]、微调独立探测器 [19,38,40,44]、多采样一致性检查 [31]。  
  - 内部状态方法：token 概率/熵 [17,30,52]、ReDeEP 的 ECS+PKS 机制分解 [47]。  

- **引文幻觉专门研究**  
  - 黑盒评估：让模型回答追问以检验是否真读过源文 [1,37]；法律检索工具实证分析 [28]。  

- **Transformer 机制解释**  
  - 注意力即“读取”通路，FFN 即“参数回忆”通路 [7,13,42]；FFN 可视为键-值记忆 [11]。  
  - 句首 token 作为 attention sink 用于长上下文信息整合 [3,4,12]。  

- **长文本 RAG 与归因漂移**  
  - 32 k–2 M token 窗口模型加剧“attributional drift”风险 [6,23]。  

- **数据集与评估**  
  - TREC NeuCLIR 2024 报告生成任务 [20]；LLM-as-a-judge 的 ARGUE 框架 [32] 与 κ 一致性验证 [33]。

## 解决方案

论文把“引文幻觉”拆解为模型内部两条信息通路——Attention（读取上下文）与 FFN（调用参数记忆）——在生成引文瞬间的协同失败，并给出可量化的诊断方案。核心步骤如下：

1. 机制建模  
   将 Transformer 的残差流写成可加形式  
   $$x_i^{(l)}=x_i^{(l-1)}+v_{\text{attn},i}^{(l)}+v_{\text{ffn},i}^{(l)}$$  
   从而把“读”与“忆”显式解耦为两个独立向量。

2. 四项机制得分  
   - **CAS**（Context Alignment Score）：仅对源文档 token 做注意力加权，再与生成引文 token 的隐藏状态求余弦，度量“是否真读到该文献”。  
   - **BAS**（Beginning-of-sentence Attention Score）：取句首 token 的注意力权重，度量“是否利用 attention sink 做长文信息整合”。  
   - **PFS**（Parametric Force Score）：取 FFN 更新向量的 L2 范数 $||v_{\text{ffn}}^{(l)}||_2$，度量“参数记忆被调用的强度”。  
   - **PAS**（Pathway Alignment Score）：计算 $v_{\text{attn}}^{(l)}$ 与 $v_{\text{ffn}}^{(l)}$ 的余弦相似度，揭示两条通路是协同、正交还是对抗。

3. 特征工程与分类  
   对 32 层×32 头的原始得分做“相关性剪枝→层内统计聚合→时序趋势提取”，最终每 citation token 仅保留 4 维稳健特征，用 Logistic Regression/LightGBM/EBM 做二分类。

4. 规模演化分析  
   3 B 模型需用全部组件，签名是“四项得分全部更高→通路一致强化”；8 B 模型只需 top-25 % 组件，签名变为“PFS 与 BAS 仍高，但 PAS 反而更低→通路正交贡献”。由此否定“参数知识越少越好”的简单假设。

5. 实验验证  
   在 NeuCLIR 长文档报告生成任务上，FACTUM 四特征模型相对 ReDeEP 基线 AUC 提升最多 37.5 %，且 precision-recall 更均衡；消融实验表明 PAS 与 BAS 对性能增益不可或缺。

## 实验验证

实验围绕“长文本、多文档、单引文”场景展开，系统验证 FACTUM 能否在 token 级检测引文幻觉，并揭示其机制签名随模型规模的演化。主要实验与结果如下：

1. 数据集与标注  
   - 选用 TREC NeuCLIR 2024 英文报告生成任务，每例输入 15 篇机译英文文档，输出数百至上千 token 的长文。  
   - 用 Llama-3.1-70B-Instruct 作“LLM-as-a-judge”，按 ARGUE 框架对引文 digit token 做“是否被源文支持”二值标注；经温度扰动稳定性 <1.5 %，人工子集 κ=0.68，确认标注可靠。  
   - 最终样本：3 B 模型 301 个引文 token（208 正/93 幻），8 B 模型 572 个（465 正/107 幻）。

2. 对比基线  
   - 机制型：ReDeEP 的 ECS+PKS。  
   - 置信型：Perplexity、LN-Entropy、Energy、P(True)。  
   所有方法均只使用模型内部信号，保证公平。

3. 主实验—分类性能  
   - 采用 10 折分层交叉验证，报告级切分防止泄漏。  
   - 结果（AUC / F1）：  
     – 3 B：FACTUM 0.715 / 0.565，较 ECS+PKS 提升 7.0 % / 15.1 %。  
     – 8 B：FACTUM 0.737 / 0.446，较 ECS+PKS 提升 37.5 % / 53.8 %。  
   - 消融：去掉 PAS 或 BAS 任一项，AUC 下降 3–7 个百分点，证明“通路交互”与“attention-sink”信号不可或缺。

4. 机制签名检验  
   - 对“完整特征集”做单侧 Mann-Whitney U 检验：  
     – 3 B（100 % 组件）：正例 CAS↑ BAS↑ PAS↑ PFS↑ 均 p<0.001。  
     – 8 B（top-25 % 组件）：正例仍 BAS↑ PFS↑，但 PAS↓ 且 CAS 不显著，支持“规模增大后通路走向正交贡献”假设。

5. 案例诊断  
   - 对图 1 同一事实、不同引文的两条生成轨迹进行逐层得分可视化：  
     – 正确引文：CAS、BAS、PFS、PAS 同时高→通路协同。  
     – 幻觉引文：CAS、BAS 骤降，PFS 仍高，PAS 接近 0→“参数记忆强行输出，注意力未 grounding”，直观呈现 attributional drift 的机制过程。

6. 敏感性分析  
   - 剪枝比例 k 从 10 % 到 100 % 扫描：3 B 最佳 k=100 %，8 B 最佳 k=25 %，进一步验证“大模型只需局部 specialist 组件”观点。  
   - 替换分类器（Logistic/LightGBM/EBM）与替换聚合统计（mean/std/linear slope/FFT）均保持 FACTUM 领先，说明信号稳健。

综上，实验从“检测精度—机制可解释—规模演化—案例诊断”四维度共同支撑核心结论：引文幻觉是注意力与 FFN 协同失败，且该失败模式随模型规模可预测地演化。

## 未来工作

以下方向可延续 FACTUM 的思路，继续深化对“引文幻觉”乃至更广幻觉现象的理解与治理：

- **跨模型与跨架构验证**  
  - 在 GPT、Mistral、Gemini 等不同系列上复现四项机制得分，检验“规模演化”结论是否普遍成立。  
  - 将框架扩展到 MoE、混合架构或 RAG-专用模型，观察通路协同模式是否因结构差异而变。

- **多语言与跨模态场景**  
  - 对中文、多语 NeuCLIR 原文直接测试，考察语言差异是否影响 attention-sink 位置与 PAS 分布。  
  - 引入图文、图表检索，验证“视觉上下文”是否同样存在 citation-visual 幻觉及对应机制签名。

- **细粒度归因与干预**  
  - 利用 PFS 与 PAS 的层间峰值定位“关键知识神经元”，通过 FFN 消融或方向抑制，看能否在保持事实正确的前提下强制纠正引文。  
  - 对 attention head 做 knock-out，验证 CAS/BAS 高贡献头是否即为“引用 specialist”。

- **长文本动态演化追踪**  
  - 将 FACTUM 得分按 token 位置展开，量化 attributional drift 的累积速度，预测“在第几句之后最易出现幻觉”。  
  - 结合滑动窗口或分段 summary，设计早期预警阈值，实现生成过程中的实时回退/重检索。

- **多引文与篇章级聚合**  
  - 把 token 级得分上卷到句子、段落，研究“同一句话多源引用”“成组幻觉”时的通路特征。  
  - 探索引用链（citation chain）间的依赖关系，判断模型是否因前文错误引用而级联产生后续幻觉。

- **与检索器联合优化**  
  - 将 FACTUM 得分作为奖励信号，用强化学习微调生成器，或做 differentiable rerank，让检索-生成协同降低幻觉率。  
  - 考察“先检索-后判断”流水线：用 PAS 低分触发二次检索，动态补充更相关的段落。

- **人类认知对齐与用户研究**  
  - 设计眼动或置信标注实验，验证 FACTUM 给出的“可疑引文”标记是否与人类阅读时的不信任区域一致。  
  - 探索不同领域（医学、法律）读者对 citation 标记的敏感度差异，调整 precision-recall 偏好。

- **解释可视化与教育体系**  
  - 开发交互式界面，实时显示 CAS、PAS 等曲线，帮助从业者理解模型为何“张冠李戴”。  
  - 将机制得分引入写作辅助工具，指导用户在提示层面减少幻觉诱因（如明确来源指令、分步引用）。

- **扩展至其他类型幻觉**  
  - 把框架应用于“事实内含幻觉”（factual hallucination）或“自我矛盾”，检验 FFN-Attention 协同失败是否通用。  
  - 研究对话场景下的“角色幻觉”（persona hallucination），看 PAS 是否为衡量“参数人格 vs. 上下文指令冲突”的有效指标。

- **理论深化**  
  - 从信息论角度量化 v_att 与 v_ffn 的互信息，建立“协同-正交-对抗”三区间与生成风险的概率映射。  
  - 结合随机矩阵理论，解释为何大模型在稀疏组件下反而需要降低 PAS 以获得更好性能，探索“过度对齐”导致的容量损失。

这些探索可逐步把 FACTUM 从“事后诊断”升级为“事前预防-事中干预-人机共信”的全链路解决方案。

## 总结

- **问题**  
  长文本 RAG 中模型常把事实正确但来源错误的信息归因到无关文献，形成“引文幻觉”，现有研究仅归因于“过度依赖参数知识”，缺乏对内部机制的细粒度解释。

- **方法**  
  提出 FACTUM 框架，把 Transformer 残差流拆成 Attention（读取上下文）与 FFN（调用参数）两条可加通路，定义四项机制得分：  
  - CAS：引文与源文档的语义对齐  
  - BAS：句首 attention-sink 使用强度  
  - PFS：FFN 更新幅值  
  - PAS：两通路向量余弦（协同/正交/对抗）  
  经组件剪枝与层间聚合后，用 4 维特征训练简单分类器，实现 token 级幻觉检测。

- **实验**  
  在 TREC NeuCLIR 2024（15 文档、长报告）上测试 Llama-3.2-3B 与 3.1-8B：  
  - AUC 最高 0.737，相对最强基线提升 37.5%，precision-recall 更均衡。  
  - 3B 需用全部组件，正确引文四项得分均显著更高（协同强化）。  
  - 8B 仅用 top-25 % 组件即可最优，此时 PAS 反而更低，表明大模型依赖“正交贡献”而非简单一致。

- **结论**  
  引文幻觉本质是 Attention-FFN 协同失败，且该机制签名随模型规模演化；FACTUM 通过捕捉这一动态，成为新的 state-of-the-art 可解释检测器，并为后续干预与可信 RAG 提供细粒度信号。
