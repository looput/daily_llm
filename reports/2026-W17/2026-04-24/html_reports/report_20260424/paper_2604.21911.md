# When Prompts Override Vision: Prompt-Induced Hallucinations in LVLMs

**领域**: Multimodal

## 摘要

> 本文针对大型视觉语言模型（LVLMs）中的幻觉问题进行了深入研究，提出了HalluScope基准来系统分析幻觉产生的根源，并开发了HalluVL-DPO微调框架来缓解由文本指令先验引发的幻觉。研究发现幻觉主要源于模型对文本先验和背景知识的过度依赖，特别是通过文本指令引入的信息。实验表明，优化后的模型能有效减轻目标幻觉模式，同时保持或提升在其他幻觉基准和视觉能力评估上的性能。作者团队承诺公开评估基准、训练数据集和代码，支持可复现性和进一步研究。

## 问题定义

这篇论文主要解决**大型视觉语言模型（Large Vision-Language Models, LVLMs）中的幻觉问题，特别是由文本提示（prompt）诱导的幻觉现象**。

具体而言，论文针对以下几个层面的问题：

### 1. 幻觉成因的诊断与解耦
现有幻觉评估基准（如 POPE、CHAIR、MMHAL-Bench 等）将幻觉视为单一现象，无法区分不同成因：
- **视觉感知限制**（Visual perception limitations）：视觉编码器无法识别图像内容
- **学习到的语义共现先验**（Learned object co-occurrence priors）：模型依赖训练数据中的对象共现统计（如看到"桌子"就推断有"椅子"）
- **文本指令预设**（Instruction presuppositions）：问题本身隐含了不存在对象的假设（如问"椅子的颜色是什么？"而图中根本没有椅子）

### 2. 文本先验对视觉证据的压制
论文发现，随着视觉主干网络的改进，现代 LVLMs 的幻觉主要并非源于视觉感知失败，而是源于**语言模态对视觉模态的主导**。即使视觉识别准确，模型仍会生成错误回答，因为其输出更受学习到的对象共现知识和文本指令预设的影响，而非实际图像内容。

### 3. 缺乏针对性的缓解方法
现有缓解方法多为事后干预（training-free）或基于通用偏好优化，缺乏专门针对**文本指令诱导型幻觉**的系统性解决方案。特别是，现有数据集通常依赖闭源模型或人工标注，难以扩展，且未专门针对文本先验导致的幻觉。

### 解决方案概述
为应对上述问题，论文提出了：
- **HalluScope**：一个诊断性基准，通过构造四类问题（正面对象识别、随机对象识别、对抗性对象识别、对抗性预设属性查询）来量化不同因素对幻觉的相对贡献
- **HalluVL-DPO**：基于样本信息量加权 Direct Preference Optimization（DPO）的微调框架，通过构造包含明确视觉 grounding 信号偏好对的数据集，引导模型优先选择基于视觉证据的回答而非受文本先验诱导的幻觉回答

实验表明，经过 HalluVL-DPO 优化的模型在对抗性预设问题（Adversarial Presupposition）上的准确率可从不足 6% 提升至超过 80%，同时在其他幻觉基准和通用多模态能力上保持或提升性能。

## 相关工作

该论文的相关研究主要集中在**大型视觉语言模型（LVLMs）幻觉的评估与缓解**两大方向，具体如下：

### 1. 幻觉评估基准

根据幻觉表现形式的不同，现有评估工作可分为：

- **开放式文本生成幻觉**：评估生成内容与视觉输入不符的情况，主要指标包括：
  - **CHAIR** [34]：衡量图像描述中对象幻觉率
  - **SHR** [51] 与 **ALOHa** [29]：更细粒度的描述级别幻觉评估

- **对象属性幻觉**：评估模型为图像中对象生成错误属性的情况，代表性工作为 **MMHalBench** [38]

- **封闭式查询幻觉**：通过询问特定对象的存在性或属性来检测幻觉，包括：
  - **POPE** [17]：评估对象存在性判断的准确性
  - **HallusionBench** [10]：针对视觉或文本线索模糊、冲突情况下的鲁棒性评估

现有基准的局限在于**将幻觉视为单一现象**，未能区分感知错误、语义共现先验或指令预设等不同成因。

### 2. 幻觉缓解方法

#### 2.1 事后干预方法（Training-free）
这类方法基于特定假设进行推理时干预，不改变模型参数：
- **注意力机制干预**：检测并干预"幻觉注意力头" [47]；重新分配注意力远离语义信息量低的 sink tokens [13]；放大对视觉 tokens 的注意力并对比视觉与纯文本输入的 logits [22]
- **表示操控**：通过潜在空间 steering 调整隐藏层表示 [21, 28, 48]；利用中间层表示检测和抑制幻觉 [40, 39]
- **对比解码**：对比原始图像与噪声/扰动图像的输出差异（**VCD** [15]）
- **信息累积**：累积并强化视觉相关信息（AGLA [1]）

这类方法通常**增加推理时间**或需要修改模型内部实现（如注意力计算），且受限于特定假设，无法覆盖所有幻觉来源。

#### 2.2 基于优化的方法（Optimization-based）
通过调整模型权重从根本上解决幻觉，主要包括：

- **指令微调**：构造包含误导性和幻觉诱导指令的大规模数据集进行微调 [19]

- **偏好优化（Preference Optimization）**：将幻觉缓解建模为偏好选择问题，通过 DPO（Direct Preference Optimization）训练模型偏好视觉 grounded 的回答：
  - 早期工作依赖闭源视觉模型分析图像或 richly annotated 数据集（如 Visual Genome），限制了可复现性和扩展性 [51, 52]
  - **Antidote** [43]：针对反事实预设查询的偏好优化框架
  - **V-DPO** [45]：通过视觉引导的 DPO 缓解幻觉
  - **HA-DPO/HADPO** [9]：针对幻觉目标的直接偏好优化
  - **MIA-DPO** [25]：多图像增强的 DPO 方法
  - 其他相关工作 [49, 9, 43]

现有偏好优化数据集的局限在于：通常**关注一般性幻觉**而非专门针对**文本先验诱导的幻觉**，且多依赖闭源模型或特定标注数据集。

### 3. 视觉-语言模态交互研究
- **模态主导性研究**：研究表明即使视觉识别准确，现代 LVLMs 仍频繁生成错误回答，反映文本模态对视觉模态的主导 [45, 15, 3]
- **对象共现偏差**：分析训练数据中对象共现统计如何导致模型基于语义上下文而非视觉证据进行预测 [27, 30]
- **上下文学习（In-context Learning）**：探讨多模态上下文学习中的失败模式与偏差 [3, 36]

## 解决方案

该论文从**诊断分析**与**缓解优化**两个层面解决文本提示诱导的幻觉问题：

## 1. 诊断层面：HalluScope 基准

为解耦幻觉的不同成因，论文构建了 **HalluScope** 诊断基准，通过四类查询分别评估特定因素：

- **Positive Object Recognition**：查询视觉存在的对象（评估视觉感知能力）
- **Random Object Recognition**：查询与场景无关的随机缺失对象（评估视觉backbone对明显不存在对象的识别）
- **Adversarial Object Recognition**：查询语义上合理但视觉缺失的对象（评估对**学习到的对象共现先验**的依赖）
- **Adversarial Presupposition Attribute**：询问对抗性对象的属性（如"椅子的颜色是什么？"），隐含假设该对象存在（评估**文本指令预设**的诱导强度）

**关键技术细节**：
- 使用 **K-Center Greedy 算法** 在COCO caption嵌入空间中选择语义多样化的图像
- 采用 **Florence-2-large** 检测候选对象，**Grounding-DINO** 进行两阶段验证（置信度阈值+LVLM验证）
- 基于 **点互信息（PMI）** 构建对象共现图，识别与场景中现有对象共现概率高但实际缺失的对抗性对象：
  $$PMI(o_a, o_b) = \begin{cases} \log \frac{P(o_a, o_b)}{P(o_a)P(o_b)}, & \text{if } P(o_a, o_b) > 0 \\ 0, & \text{otherwise} \end{cases}$$

## 2. 缓解层面：HalluVL-DPO 框架

针对文本指令预设诱导的幻觉，论文提出 **HalluVL-DPO**，一种基于样本信息量加权的偏好优化方法。

### 2.1 加权直接偏好优化（Weighted DPO）

标准DPO对所有样本一视同仁，而 HalluVL-DPO 引入**样本信息量权重** $w(x, y_w, y_l)$，反映偏好对 $(y_w, y_l)$ 的对比强度：

$$L_{weighted DPO}(\pi_\theta; \pi_{ref}) = -\mathbb{E}_{(x,y_w,y_l)\sim D} \left[ w(x, y_w, y_l) \log \sigma \left( \beta(r_w(x) - r_l(x)) \right) \right]$$

其中 $r_w(x) = \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}$，$r_l(x) = \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}$。

权重根据响应间的**语义差距**分为三级（由外部LLM评估）：
- **权重=1**：近义改写，对比微弱
- **权重=2**：两者均遵循错误预设，但细节程度不同  
- **权重=3**：鲜明对比，正确回答否认对象存在而错误回答假设其存在

### 2.2 偏好数据集构造

构建包含 **27.4k 图像、100k+ 查询** 的合成数据集，针对三种任务类型设计偏好对：

| 任务类型 | 构造策略 | 说明 |
|---------|---------|------|
| **预设查询** (TPQ/CPQ) | Unilateral Hint Augmentation | 在指令后附加正确/错误提示（如"图中没有椅子"或"图中有椅子"），诱导生成grounded/幻觉回答 |
| **对象存在性** (POPE-style) | Unilateral Hint Augmentation | 同上，针对简单存在性查询 |
| **详细描述** | Contrastive Hint Augmentation / Post-Hoc Hallucination Injection | 解决单边提示导致的长度偏差问题；后者通过替换描述中的句子为幻觉诱导前缀（如"图中可见{对抗性对象}"）并续写，保持原描述结构 |
| **属性查询** | Model-Assisted Answer Inversion | 用外部LLM生成保留目标对象但赋予错误属性的对抗性回答，增加细粒度视觉推理难度 |

**质量控制机制**：
- 使用 Sentence-BERT 嵌入空间余弦距离筛选语义差异显著的偏好对（阈值0.9/0.95）
- 对合成图像进行**视觉验证**（Grounding-DINO确认对象存在/缺失）

### 2.3 训练与实施

- 采用 **LoRA** 高效微调（rank 64/128, $\alpha$ 128/256）
- 数据配比：CPQ : TPQ : POPE : 描述 : 属性 = 5 : 5 : 6 : 9 : 5
- 在 **LLaVA-1.5-7B** 和 **Qwen2-VL-7B** 上验证，单次训练约6小时（A100单卡）

## 3. 效果验证

- **对抗性预设查询（AdP）**：LLaVA-1.5-7B 从 5.85% 提升至 83.54%，Qwen2-VL-7B 从 57.96% 提升至 80.40%
- **对抗性对象识别（Recadv）**：显著提升（如 LLaVA 从 58.5% 提升至 76.5%）
- **一般能力保持**：在 MME、ScienceQA、MM-Vet 等通用多模态基准上性能无显著下降
- **跨模型迁移性**：生成的偏好数据在不同架构模型间具有一定迁移能力，尽管同模型数据效果最佳

## 实验验证

该论文的实验分为**主实验验证**、**消融分析**和**补充实验**三大部分，涵盖对所提基准 HalluScope 和优化方法 HalluVL-DPO 的全面评估：

## 1. 主实验验证（Section 5.2）

### 1.1 HalluScope 基准评估（Table 2, Table 3）
在提出的诊断基准上评估了两种基础模型（LLaVA-1.5-7B 和 Qwen2-VL-7B）及多种缓解方法：

- **评估指标**：正面对象识别（Recpos）、随机对象识别（Recrnd）、对抗性对象识别（Recadv）、对抗性预设属性（AdP）
- **对比基线**：
  - 原始模型（Vanilla）
  - **VCD** [15]（视觉对比解码，training-free 方法）
  - **Antidote** [43]（DPO 方法，使用原文超参数 HP-orig 和搜索后最优参数 HP-search）
  - **HalluVL-DPO**（本文方法，标准 DPO）
  - **HalluVL-DPOw**（带样本信息量加权的 DPO）

**关键结果**：
- LLaVA-1.5-7B 的 AdP 从 5.85% 提升至 83.54%（加权版 84.65%）
- Qwen2-VL-7B 的 AdP 从 57.96% 提升至 80.40%（加权版 82.83%）
- 对抗性对象识别（Recadv）显著提升（如 LLaVA 从 58.5% 提升至 81.28%）

### 1.2 跨基准泛化评估（Table 4）
验证方法在其他幻觉基准和通用任务上的性能，包括：
- **幻觉基准**：POPE、HallusionBench、CP-Bench（含 CPQ 和 TPQ）、CHAIR（CHAIRs 和 CHAIRi）
- **通用多模态能力**：MME（感知 MME-p 和认知 MME-c）、ScienceQA、MM-Vet

**发现**：HalluVL-DPO 在减少幻觉的同时，保持了原始模型在通用任务上的性能，且优于 Antidote 和 VCD 基线。

## 2. 消融实验（Section 5.3 & Section D）

### 2.1 偏好对类型贡献分析（Figure 5 左）
通过**留一法消融**评估训练数据中不同查询类型的贡献：
- 保持总样本数 20k 不变，每次移除一种偏好对类型（CPQ、TPQ、POPE、描述、属性）
- **发现**：属性查询（Attribute pairs，通过 Model-Assisted Answer Inversion 生成）对所有基准的贡献最均匀；其他类型主要对结构相似的任务有效。

### 2.2 训练数据规模影响（Figure 5 右）
在 LLaVA-1.5-7B 上评估不同训练数据量（从 5k 到 20k+）的效果：
- AdP 性能在约 20k 样本时开始饱和
- 对抗性识别（Recadv）和 CHAIR 指标也随数据量增加而改善，但较早达到平台期

### 2.3 样本加权策略效果（Section C.1, Table 5）
验证基于语义差距的加权策略有效性：
- 仅使用语义差距评分 2（中等对比）的样本：AdP 为 64%
- 仅使用评分 3（强对比）的样本：AdP 为 81.05%，但正面对象识别下降
- 混合使用（评分 2 和 3）：平衡性能，AdP 达 79.45%

### 2.4 偏好对生成策略比较（Section D.1, Table 6, Figure 9）
针对**描述任务查询**的三种生成策略进行对比：
- **单边提示增强（Unilateral Hint Augmentation）**：导致严重的长度偏差（平均 94.56 vs 185.06 tokens），生成描述过于简短
- **对比提示增强（Contrastive Hint Augmentation）**：长度一致（106.26 vs 102.96），保持描述完整性
- **事后幻觉注入（Post-Hoc Hallucination Injection）**：长度一致（173.40 vs 172.05），保留原始描述结构

定性分析（Figure 9）显示，单边提示虽消除幻觉但损失细节，后两种策略在减少幻觉的同时保持描述丰富度。

## 未来工作

基于该论文的研究发现与局限，以下几个方向值得进一步探索：

### 1. 真实世界与合成数据的混合训练
当前 HalluVL-DPO 主要依赖合成生成图像进行训练。未来可探索**真实图像与合成图像的混合策略**，特别是在开放域（open-ended）场景下的鲁棒性提升。具体而言，可研究如何在不牺牲合成数据可控性的前提下，注入真实世界的视觉复杂性（如遮挡、光照变化、罕见视角），以进一步提升模型在真实部署环境中的幻觉抵抗能力。

### 2. 架构层面的多模态对齐机制
论文发现幻觉主要源于文本模态对视觉模态的"压制"，而现有方法（包括 HalluVL-DPO）主要依赖**后训练（post-training）**的对齐。可探索在模型架构层面增强视觉-语言平衡的机制，例如：
- 设计**动态模态权重**机制，根据输入提示的置信度自适应调整视觉与文本先验的权重
- 引入**视觉锚定损失（Visual Anchoring Loss）**，在预训练阶段就强制模型的高层表示与视觉特征保持几何一致性

### 3. 细粒度幻觉类型的系统化研究
HalluScope 主要关注对象存在性幻觉与属性幻觉，但幻觉还包括：
- **关系幻觉**（如"人坐在椅子上"实际不存在）
- **计数幻觉**（对象数量错误）
- **空间位置幻觉**（相对位置关系错误）

可扩展 HalluScope 的框架，构建针对**关系推理**和**组合性理解**的诊断基准，量化模型在复杂视觉关系中的先验偏差。

### 4. 实时提示风险检测与自适应缓解
论文展示了提示预设（presupposition）的危险性。可开发**轻量级的提示风险评估模块**，在推理前检测查询中是否包含潜在的虚假预设或强语言先验，并据此动态选择解码策略（如自动触发视觉对比解码 VCD 或调整注意力分布）。

### 5. 跨语言与多语言场景
当前工作基于英语提示和 COCO 等英语标注数据集。不同语言的**语法预设差异**（如汉语的"把"字句、日语的主题标记）可能以不同方式诱导幻觉。可构建多语言版本的 HalluScope，研究语言结构对视觉 grounding 的影响，并开发跨语言的幻觉缓解方法。

### 6. 视频与多帧场景的幻觉诊断
将研究从单张静态图像扩展到**视频或多图序列**：
- **时序幻觉**：模型是否因前一帧的内容而在后续帧中产生幻觉？
- **跨帧对象一致性**：如何处理视频中的对象存在性查询，当对象仅在部分帧中出现时？
这要求扩展 PMI 计算到时序共现统计，并重新设计对抗性样本的生成策略。

### 7. 理论解释与因果分析

### 8. 人类反馈与合成数据的混合偏好优化

### 9. 推理时干预与训练时优化的协同
HalluVL-DPO 是训练时方法，而 VCD 等是推理时方法。可探索**混合策略**：
- 使用 HalluVL-DPO 微调后的模型作为基础，在推理时针对高风险查询（如包含否定词、复合名词的提示）自动启用对比解码
- 研究计算资源受限场景下的**早期退出（Early Exit）**机制，当模型对视觉 grounding 的置信度不足时触发更深的验证层

### 10. 对抗鲁棒性与安全应用
论文提到恶意使用者可通过交换 chosen/rejected 对来增强幻觉。可进一步研究：

- **安全关键领域的专门化**：将 HalluVL-DPO 应用于医疗影像（如放射科报告生成）或自动驾驶场景，开发领域特定的幻觉检测指标（如病变存在性验证）

该论文针对大型视觉语言模型（LVLMs）中的**文本提示诱导型幻觉**问题，提出了系统性的诊断基准与缓解方法，主要内容可概括如下：

## 1. 研究背景与问题定义
尽管视觉编码器能力持续提升，现代 LVLMs 的幻觉主要并非源于视觉感知失败，而是源于**语言模态对视觉模态的主导**。具体表现为：
- **学习到的对象共现先验**：模型依赖训练数据中的统计相关性（如看到"桌子"即推断"椅子"存在），而非实际视觉证据
- **文本指令预设诱导**：当查询隐含假设某对象存在时（如"椅子的颜色是什么？"），模型倾向于维持该假设而产生幻觉

现有评估基准（POPE、CHAIR 等）将幻觉视为单一现象，无法区分**感知错误**、**共现先验**与**指令预设**三类成因，限制了精准诊断与针对性缓解。

## 2. HalluScope：幻觉诊断基准
为量化不同因素的相对贡献，论文构建了 **HalluScope** 基准，包含四类诊断查询：

| 查询类型 | 评估目标 | 技术实现 |
|---------|---------|---------|
| **Positive Object Recognition** | 视觉感知能力 | 查询视觉存在的对象 |
| **Random Object Recognition** | 基础视觉判别 | 查询与场景无关的随机缺失对象 |
| **Adversarial Object Recognition** | 共现先验依赖 | 基于 $PMI(o_a, o_b) = \log \frac{P(o_a, o_b)}{P(o_a)P(o_b)}$ 识别语义合理但视觉缺失的对抗性对象 |
| **Adversarial Presupposition (AdP)** | 指令预设诱导 | 询问对抗性对象的属性，强制模型在"遵循预设"与"基于视觉否认存在"间抉择 |

基准构造采用 **K-Center Greedy 算法** 确保语义多样性，结合 **Grounding-DINO** 与 **Qwen2-VL** 进行两阶段对象验证。

## 3. HalluVL-DPO：偏好优化框架
针对文本指令诱导的幻觉，论文提出 **HalluVL-DPO**，一种基于样本信息量加权的 Direct Preference Optimization 方法。

### 3.1 加权损失函数
标准 DPO 对所有样本一视同仁，而 HalluVL-DPO 引入语义差距权重 $w(x, y_w, y_l) \in \{1,2,3\}$：

$$L_{weighted DPO}(\pi_\theta; \pi_{ref}) = -\mathbb{E}_{(x,y_w,y_l)\sim D} \left[ w(x, y_w, y_l) \log \sigma \left( \beta(r_w(x) - r_l(x)) \right) \right]$$

其中 $r_w(x) = \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}$，$r_l(x) = \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}$。权重由外部 LLM 根据"正确否认存在"与"错误假设存在"的对比强度评定。

### 3.2 训练数据集构造
构建包含 **27.4k 合成图像** 与 **100k+ 查询** 的偏好数据集，采用四种策略生成对比响应：
- **单边提示增强**：附加正确/错误提示诱导 grounded/幻觉回答
- **对比提示增强**：同时提供正反提示，消除长度偏差
- **事后幻觉注入**：替换描述中的句子为幻觉前缀并续写，保持结构完整性
- **模型辅助属性反转**：利用外部 LLM 生成保留对象但赋予错误属性的对抗性回答

数据配比为 CPQ : TPQ : POPE : 描述 : 属性 = 5 : 5 : 6 : 9 : 5。

## 4. 实验结果与发现
### 4.1 诊断发现（HalluScope）
- 现代 LVLMs 在正面对象识别（$>90\%$）与随机对象识别（$>85\%$）上表现优异，表明**视觉感知并非瓶颈**
- 对抗性对象识别准确率下降 $8\%$–$37\%$，显示**共现先验**的负面影响
- **对抗性预设查询（AdP）**性能骤降 $25\%$–$85\%$，证明**文本指令是主导性幻觉来源**

### 4.2 缓解效果
经 HalluVL-DPO 微调后：
- **LLaVA-1.5-7B**：AdP 从 5.85% 提升至 83.54%，对抗性识别从 58.5% 提升至 76.5%
- **Qwen2-VL-7B**：AdP 从 57.96% 提升至 80.40%

同时在 POPE、HallusionBench、CHAIR 等泛化基准上持续改进，并在 MME、ScienceQA、MM-Vet 等通用任务上保持性能。

## 5. 贡献与资源
- **HalluScope**：首个系统解耦幻觉成因（感知 vs 先验 vs 预设）的诊断基准
- **HalluVL-DPO**：首个专门针对文本指令诱导幻觉的偏好优化框架，开源训练数据、基准构造流程与模型检查点
- **实证洞察**：揭示随着视觉主干改进，LVLM 可靠性问题已从感知层面转向**跨模态对齐层面**
