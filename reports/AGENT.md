# DailyPaper · AI Agent 访问指南

本站每日自动抓取、筛选、分析 arXiv 大模型论文，并以**分层 Markdown** 结构发布，供 AI Agent 按需加载，避免上下文过长。

---

## 资源结构

```
/reports/index.json          # 入口：所有报告的目录索引（~5 KB）
/reports/{week}/{report}.md  # 轻量主索引：统计 + 论文目录（~7 KB）
/reports/{week}/{report}/
    {Domain}.md              # 单领域：趋势分析 + 该域论文摘要（5–20 KB）
    paper_{arxiv_id}.md      # 单篇：完整六段式分析（8–30 KB）
```

---

## index.json 字段说明

```jsonc
{
  "updated": "2026-03-20",       // 最近更新日期
  "weekly": [                    // 周报列表，按时间倒序
    {
      "week": "2026-W12",        // ISO 周编号
      "date": "2026-03-16",      // 该周首日
      "n": 112,                  // 精选论文总数
      "md": "/reports/...",      // 轻量主索引 URL（可选，旧报告无此字段）
      "d": {                     // 各领域文件 URL（可选，有分层文件才有）
        "Agent":      "/reports/.../Agent.md",
        "Multimodal": "/reports/.../Multimodal.md"
      }
    }
  ],
  "daily": [                     // 日报列表，按时间倒序
    {
      "date": "2026-03-17",      // 日期
      "n": 37,                   // 精选论文数
      "md":  "...",              // 同上（可选）
      "d":   { ... }             // 同上（可选）
    }
  ]
}
```

> **注**：老报告（分层文件生成前）无 `md` / `d` 字段，只有 `n`。

## 推荐访问流程

### 场景 A：了解最新研究动态

```
1. GET /reports/index.json
   → 读 daily[0]，得到最新日期和论文数

2. GET daily[0].md
   → 7 KB，获取当日所有论文的标题、评分、所属领域
   → 查看"领域趋势摘要"表，决定感兴趣的领域

3. GET daily[0].d["Agent"]          ← 按需选择领域
   → 20 KB，获取 Agent 领域的趋势分析 + 所有论文摘要

4. 从域文件中的 [📖 全文分析] 链接，按需获取单篇详情
   → 每篇 8–30 KB
```

### 场景 B：追踪某一具体领域（如 RLHF）

```
1. GET /reports/index.json
   → 找到所有含 "RLHF" key 的报告（检查 d 字段）

2. 按需 GET 各期的 d["RLHF"]
   → 每个领域文件包含该期完整的趋势分析和论文摘要
```

### 场景 C：查找某篇具体论文

```
1. GET /reports/index.json
   → 定位到目标日期的报告

2. GET 该报告的 md（主索引）
   → 在"论文详情"表中搜索标题，获取 paper_{id}.md 链接

3. GET paper_{id}.md
   → 获取完整分析
```

### 场景 D：只看周报摘要

```
1. GET /reports/index.json
   → 读 weekly[0]（最新周报）

2. GET weekly[0].md
   → 全周精选论文目录 + 各领域链接

3. 按需深入各领域或单篇
```

## 典型上下文消耗估算

| 操作 | 消耗 Token（约） |
|---|---|
| 读 index.json | ~1,500 |
| 读一份日报主索引（md） | ~2,000 |
| 读一个领域文件 | ~5,000–15,000 |
| 读一篇论文详情 | ~2,000–8,000 |
| 读原始全量 Markdown（不推荐） | ~180,000+ |

**建议**：单次对话控制在 3–4 步以内，优先用领域文件而非全量索引。
