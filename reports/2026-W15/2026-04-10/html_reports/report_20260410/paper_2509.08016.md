# Video Parallel Scaling: Aggregating Diverse Frame Subsets for VideoLLMs

**arXiv**: [2509.08016](https://arxiv.org/abs/2509.08016) · [PDF](https://arxiv.org/pdf/2509.08016)  
**领域**: Multimodal  
**作者**: Chung, Nam, Kim, Go, Park, Kim, Lee, Ha 等 9 人

## 摘要

> 本文提出了一种名为Video Parallel Scaling (VPS)的推理时方法，旨在解决视频大语言模型（VideoLLMs）在处理长视频时面临的计算成本高昂和性能下降的瓶颈问题。该方法通过并行处理视频帧的不同子集并聚合输出，有效扩展了模型的感知带宽，而无需增加其上下文窗口。论文在多个基准测试（如Video-MME和EventHallusion）和不同规模的模型（2B-32B）上进行了广泛的实验，证明了其有效性和优越性。作者团队来自韩国科学技术院（KAIST）和Naver公司，在计算机视觉和人工智能领域具有深厚的研究背景。

## 问题定义

论文旨在解决 Video Large Language Models（VideoLLMs）在**增加输入帧数以获取更细粒度时间信息**时遇到的**计算成本激增与性能下降**这一核心瓶颈。具体而言：

- **问题背景**：现有 VideoLLMs 通常只能对视频进行**固定帧数（如 ≤32 帧）或低帧率（≤1 fps）的子采样**，否则上下文长度会爆炸，导致显存占用与推理 FLOPs 呈二次增长，并出现“上下文衰减”（context-rot）现象，准确率反而下降。  
- **关键矛盾**：为了理解**长时、高速、精细运动**（如计数、顺序、因果推理），模型需要“看到”更多帧，但简单地把更多帧塞进同一上下文窗口既不可扩展也不经济。  
- **论文目标**：在**不增加单流上下文长度**的前提下，**扩大模型的感知带宽（perceptual bandwidth）**，使其能够利用视频中**被常规子采样丢弃掉的大量视觉信息**，从而提升对细粒度运动、长时事件、时序关系的理解能力。

## 相关工作

论文将相关研究划分为两大类，并在第 2 章给出系统回顾。以下按“非扩展型”与“扩展型”两栏归纳，同时补充与 VPS 最贴近的同期工作。

| 类别 | 代表方法 / 论文 | 核心思想 | 与 VPS 的区别 |
|---|---|---|---|
| **非扩展型（compute-static）** | AKS / BOLT (CVPR 2025) | 用 query-frame 相似度选“关键帧”，减少冗余 | 只挑一次帧，无法利用被丢弃帧的信息；无并行 |
|  | VideoTree (CVPR 2025) | 层级式帧选择，对长视频建树状表示 | 同样受限于单流帧预算 |
|  | SlowFastLLaVA (arXiv 2024) | 双流不同帧率拼接，一次性输入 | 帧数仍一次性压入上下文，长度线性增加 |
|  | SlowFocus (NeurIPS 2024) | 多频注意力 + 片段定位 | 修改模型结构，非纯推理方法 |
|  | Token Merging / FrameFusion | 在视觉端合并 patch 减少 token 数 | 降低分辨率，而非补充新帧 |
|  | 对比解码 CD / TCD / RITUAL | 在 logit 空间做正负对比或数据增广 | 单流输入，仅改变解码规则 |
| **扩展型（compute-scaling）** | Self-consistency (ICLR 2023) | 多流同输入、多数投票 | 每流看到的帧完全相同，无法引入新视觉信息 |
|  | Best-of-N / Speculative Rejection | 多流+奖励模型选最佳 | 需外部奖励函数，且帧输入不变 |
|  | Chain-of-Thought / Tree-of-Thoughts | 顺序或树状推理，扩展“思考步数” | 扩展的是文本推理步，而非视觉帧 |
|  | ParScale (arXiv 2025) | 训练时为 J 个流学 J 组 prefix，推理并行 | 需要额外训练；VPS 完全免训练，用帧偏移即得多样性 |
| **同期最相关** | 多帧并行推理（本文） | 各流看**互补、不重叠的子采样帧**，概率加权聚合 | 唯一在**推理期**通过**纯视觉多样性**实现扩展，且与上述扩展/非扩展方法正交 |

综上，VPS 的差异化定位是：  
- **免训练、纯推理期**的并行扩展策略；  
- **不增加单流上下文长度**，却能让模型“看到”被常规子采样丢弃的帧；  
- 与现有帧选择、对比解码、自一致性等方法**正交可叠加**。

实验围绕“**是否有效**”“**为何有效**”“**怎么用更好**”三个层次展开，覆盖 3 大家族、9 个规模（2 B–32 B）、2 大主流 benchmark，共 5 类实验。

1. 主实验：横向验证有效性  
   - Benchmark：Video-MME（900 视频，2 700 问答，17 min 级长视频）与 EventHallusion（400 视频，711 问答，20 s 级短视频）。  
   - 变量：帧数 2–32，并行流数 J = 2 / 4。  
   - 结果：  
     – 9 个模型全部一致提升，最长视频、最大模型增益越明显（↑1.6–4.1 %）。  
     – 当基线因帧数增加而性能饱和或下降时，VPS 仍随 J 线性上升，见图 2、图 5。

2. 消融对比：与同类“并行扩展”方法 PK  
   - 对手：Self-consistency（同输入、多数投票）。  
   - 控制：相同总推理次数。  
   - 结果：VPS 在相同预算下平均高出 1.8–3.4 %，证明“**不同帧 > 同帧多次**”，见图 4。

3. 自由文本生成评估  
   - 任务：EventHallusion 单句视频描述。  
   - 指标：LLM-as-a-judge（Gemini-2.5）、Sentence-Similarity、ROUGE-L。  
   - 结果：VPS 在三项指标上均优于基线， hallucination 明显减少，见表 2、表 8。

4. 正交性测试：与其他解码策略叠加  
   - 组合：VPS + TCD（时序对比解码）或 VPS + RITUAL（图像增广对比）。  
   - 结果：在 Video-MME 与 EventHallusion 上**叠加后仍持续提升**，说明 VPS 增益与现有 logit-级技巧正交，见表 4。

5. 帧采样策略深入  
   - 候选：Dense 采样、BOLT  relevance 采样、 canonical 均匀偏移。  
   - 结论：  
     – 帧预算极少时，BOLT 可进一步降低 bias；  
     – 帧预算充足时，**均匀偏移已接近最优**，验证理论分析，见表 5。

综上，实验不仅展示了 VPS 的**普适性与可扩展性**，也验证了“**多样性帧采样 + 概率融合**”这一核心设计的必要性，并给出与其他方法协同的实践指南。




Q5: 有什么可以进一步探索的点？


- **动态权重**  
  当前各流权重固定为 1/J。可尝试以信息论度量（预测熵、互信息、置信度）或强化学习在线调整 w_j，使“高共识、低冲突”的流获得更大话语权。

- **可学习的融合函数**  
  将简单加权替换为轻量级元网络（meta-ensemble）或多 agent 辩论机制，让各流在融合前进行一轮“交互”，有望进一步降低 ¯B(J) 与 ρ。

- **帧采样策略的自适应搜索**  
  在推理阶段用贪心 / MCTS 搜索最优 {K_j}，使各流互补性最大；或与 VPS 并行运行多种采样策略，再对结果二次融合。

- **与视频特定先验结合**  
  引入光流、动作识别或音频模态的伪标签，作为额外偏置项指导帧选择，可进一步减小单流 bias Bj。

- **低资源场景下的极限并行**  
  研究在边缘设备（NPU、手机）上通过时间片复用或梯度检查点实现“伪并行”，使 VPS 的 J 流成本接近单流。

- **跨模态扩展**  
  将“并行多视角”思想迁移至音频、激光雷达或多摄像头场景，构建统一的 Multimodal Parallel Scaling 框架。

- **理论深化**  
  在更一般的多模态 scaling law 框架下，定量刻画视觉 token 与文本 token 的边际效益，指导不同预算下的最优 J-K 分配。

### 论文核心速览  
**题目**：Video Parallel Scaling (VPS) – 无需训练、在推理期用“并行换帧”提升 VideoLLM 的时序感知能力。

|---|---|

| **理论** | 将 Chinchilla 缩放律推广到“部分观测+多流”场景：只要帧子集低相关(ρ≈0)，有效参数随 J 增大而 NJ^(1/α)，损失更快下降。 |

**一句话总结**：VPS 让模型“一次只看 K 帧，却像看了 J×K 帧”，在推理期低成本扩展感知带宽，突破视频理解中的帧数瓶颈。
